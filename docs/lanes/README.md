# Lanes: one content lane per TikTok account

Each account gets its own lane so they don't compete and TikTok can learn each audience. Never post the same video on
two accounts (TikTok holds back copies: re-uploads got 205 and 8 views vs 117K for the original). Every producer brief names
its lane; read that lane's file before writing the story.

| Account | Lane | File | Slots (PT) |
|---|---|---|---|
| @ed._.studios (main) | unhinged funny what-ifs | `unhinged.md` | 1 PM + 6 PM daily |
| @ed_.studios | science what-ifs | `science.md` | 1 PM + 6 PM daily |
| @ed._.sims | good-ending pet sims: recurring hero Pip the corgi puppy, a series (not biographies; they flopped) | `lane3.md` | 1 PM + 6 PM daily |

Biographies (`docs/BIOGRAPHY.md`) stay in the harness, but no account runs them.
