# Reference: @simplysimulated (analyzed 2026-10-22)

The user pointed at this post as the model for "generally interesting" what-ifs:
**"what if all men disappeared?"** (posted Oct 11). Logged out, it showed **841.3K likes, 16.1K comments, 60K saves, 62.3K shares**. It runs 76 s.
Frames were sampled every ~5 s in the in-app browser (TikTok works logged out; dismiss the login modal, then seek `video.currentTime`).

## Structure (what to copy)
- **0–7 s cold open:** an aerial city shot with the title centered in a serif ("What if all **men** disappeared?", keyword in color) and a small icon pair above it.
  A **countdown HUD** at left ("MEN VANISH IN 0:06.700") ticks down to the event.
- **"SECOND 0"**, then a **time-stamped consequence ladder**: +10 SEC (driverless cars roll), +1 MIN (unmanned building sites),
  +5 MIN (phones: "Mom · 23 missed calls"), +1 DAY (parliament "NO QUORUM", 72.5%), +3 DAYS (power grid fails, city dark),
  +1 MONTH (women run food + water), +9 MONTHS (births still happen: a big counter, 41,662,000), +10 YEARS (the first boys grow up),
  +25 YEARS ("In time, men are back"), Earth from space ("Without men, the world breaks. But it does not end.").
- **End card:** "WHO WOULD LAST LONGER?" → **WOMEN**, with one line of reasoning. It's comment bait (people argue).
- **HUD:** small left-side label + big elapsed-time value ("+1 DAY") in serif, plus an optional stat line above the scene (72.5%, 41,662,000).
- **Every beat = a new location + one italic subtitle** (~5–6 s each). Grey-blue daylight, low-poly city, no faces up close.
- **The hook is a loss that everyone can picture**, and the **turn is hope/recovery driven by real biology** (births continue).

## How EDStudio adapted it (video 004, "every human disappeared except you")
- Kept: SECOND 0 → +1 MINUTE → +1 DAY → +2 DAYS → +3 WEEKS → +4 YEARS stamps in the HUD time line, the phone beat (yours: "Mom · calling…",
  everyone else's phones ringing on the sidewalk), the grid failing in days, a counter that *is* the plot (PEOPLE ON EARTH 8,231,604,112 → 1).
- Changed: one set (city.js) re-dressed per beat instead of a new location each time; a nightly ritual (8:14 PM flashlight from the roof)
  replaces the vignette list; ending = a far window blinks back (counter 1 → 2, gold) + end card question "Who would you look for first?".
